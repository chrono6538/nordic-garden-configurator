Model-by-model: how NGB compares once rivals are specced to the same standard

Every competitor below is priced through its own configurator and built up to NGB's all-inclusive spec — insulation, double glazing, a finished floor, a concrete base, professional installation and a maintenance-free exterior. Where a rival can't reach that (insulation is a paid extra, the base is left out, or the cladding is timber that needs treating), it's flagged on the row.

Compiled 11 August 2026 · competitor figures from each brand's own site (incl VAT) · NGB = Ultimate Package · every row links to source

What the deep dive shows

  • Spec them up and the gap closes. At ~9 m², NGB Ultimate is about £21,699 in colour (£18,299 white). Once rivals add what NGB includes as standard, the genuinely-comparable ones land right around NGB: SMART Ultra ≈ £17k (Extro/Duo, once the concrete base is added), Booths ≈ £19k, Cabin Master ≈ £17–22k, eDEN ≈ £25.5k, Green Retreats G/A ≈ £24–31k, Crown ≈ £19–22k before its concrete base.
  • The cheapest headlines aren't like-for-like. Malvern's "from £4,490–£5,425" is an uninsulated timber shell — Malvern's own fully-specced RRPs are £16.8k (7.5 m²) to £38.2k (17.9 m²), and it still offers no concrete base and uses sub-NGB (~16mm) glazing. Green Retreats' B-Range headline is "building + install only" — floor, base and a maintenance-free skin are all extra (POA).
  • Where rivals undercut, they drop the concrete base or the maintenance-free skin. SMART and Crown quote the building but bill the concrete base separately (SMART from £1,780; Crown POA). Booths uses composite feet, not concrete. Cabin Master, eDEN, Green Retreats G/A and Crown are timber — they need periodic treatment; only NGB (uPVC), Booths (steel/uPVC), Green Retreats X1 (metal) are genuinely maintenance-free.
  • NGB's honest edges: concrete base included as standard, maintenance-free uPVC, and installed price certainty. Where NGB is beaten on paper (Booths 25-yr guarantee; Crown triple glazing + AC; Green Retreats 12–20-yr), it's flagged in each row so you can see exactly what you're trading.
